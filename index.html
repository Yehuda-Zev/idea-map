Drag on empty space to create your first box
Drag empty space: new box · Drag from a box border: arrow · Drag from an arrow: branch (makes a node) · Drop on an arrow: join (makes a node) · Drag a node to move it · Wheel: zoom · Right/middle-drag or Space+drag: pan · Box selected: corners resize, corner button collapses (hold 2s = all) · Arrow selected: drag end dots, Swap reverses · Double-click: rename / label · Shift-click: multi-select · Ctrl+A: select all (or a selected box's text) · Del: delete · build 8
